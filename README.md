# riverside-footer

Custom page designs for jewishriverside.com, loaded through one line in the site's
ChabadOne footer:

```html
<script src="https://virtualshliach.github.io/riverside-footer/footer.js"></script>
```

| File | Page | Status |
|---|---|---|
| `sukkot-5787.js` | Sukkot & Simchat Torah (7457011) | On (past event) |
| `chanukah-2026.js` | Chanukah Festival 2026 (draft 7553387) | Draft |

Changes pushed to `main` show on the site within about 10 minutes. See `CLAUDE.md`
for the rules every change follows.
